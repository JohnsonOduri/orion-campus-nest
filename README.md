# Orion Campus

Build a complete, production-ready, responsive AI-powered campus management web application called "ORION Campus Companion" for IIIT Kottayam.

The application should be modern, fast, scalable, and look like a premium SaaS product with a subtle pixel-art inspired design. The UI should be visually rich without becoming cluttered or childish.

The application must be fully responsive and optimized for Desktop, Laptop, Tablet and Mobile browsers.

The website should feel like a combination of Linear, Notion, Raycast, Discord, Arc Browser and modern dashboard applications while incorporating subtle retro pixel-art decorations inspired by classic campus simulation games.
